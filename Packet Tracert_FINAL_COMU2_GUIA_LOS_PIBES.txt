CONFIGURACIÓN EN ROUTERS (SedeA y SedeB)
Hacer lo mismo en ambos routers (solo cambiando el hostname)

enable
conf t
hostname SedeA  	--->	  PARA SEDE B: hostname SedeB
ip domain-name finalcomu.com (Configurar dominio que es necesario para SSH)
username admin secret Admin123 (Crear usuario seguro)
enable secret Class123 (Contraseña modo privilegiado)
crypto key generate rsa (Generar claves RSA que es para SSH)

Cuando preguntr:
How many bits? --> 1024

- Acceso remoto VTY (Usa usuario creado y desactiva Telnet):
line vty 0 4
login local
transport input ssh
exit

- configurar consola:
line console 0
password cisco
login
exit

- Banner de seguridad:
banner motd #ACCESO SOLO A PERSONAL AUTORIZADO#

- Encriptar contraseña:
service password-encryption

- Guardar configuración:
end
write memory

CONFIGURACIÓN EN SWITCHES
Haz esto en TODOS los switches (LAN1, LAN2, LAN3, LAN4)

enable
conf t
hostname SW-LAN1 (nombre del Switch (SW-LAN2 o SW-LAN3 o SW-LAN4))
username admin secret Admin123 (Usuario)
enable secret Class123
ip domain-name finalcomu.com
crypto key generate rsa
Cuando preguntr:
How many bits? --> 1024

- VTY:
line vty 0 4
login local
transport input ssh
exit

- Consola:
line console 0
password cisco
login
exit

- Banner:
banner motd #ACCESO RESTRINGIDO#

- Apagar puertos no usados:
interface range fa0/10 - 24
shutdown

- Guardar:
end
